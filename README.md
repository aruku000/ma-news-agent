### A の使い方（2026-11-04 実装）
- 毎朝の実行で、フォルダ「M&Aニュース音声」の `ma_news_latest.mp3`（音声）と `ma_news_latest.md`（要約）が、その日の中身に差し替わる。日付つきのファイルはこれまでどおり残る
- ファイルIDは変わらない（`drive.json` の `latest`）。だからホーム画面のショートカットは一度作れば毎朝そのまま使える

  - 要約：https://drive.google.com/file/d/16Y0f6IbkFfND-NQfYX27oGdrUL56edYG/view

- `ma_news_latest.mp3` を Drive で消したり名前を変えたりしないこと（消すと次の朝に新しいIDで作り直され、ショートカットの作り直しが要る。そのときはログに警告が出る）

#### 山田さんの初回設定（一度だけ）
**Android（Google ドライブアプリ）**
1. ドライブアプリで「M&Aニュース音声」フォルダを開く
2. `ma_news_latest.mp3` の右の「︙」をタップ
3. 「ホーム画面に追加」をタップし、出てきた確認で「追加」（またはアイコンを長押しして置く）
4. 翌朝からはホーム画面のアイコンを1タップで、その日の音声が開く

**iPhone（Google ドライブアプリ）**
iPhone のドライブアプリには「ホーム画面に追加」が無い。代わりに次のどちらかにする。
- 案1（手軽）：ドライブアプリで `ma_news_latest.mp3` の「︙」→「スター付き」に追加。毎朝ドライブアプリ下の「スター付き」タブ → タップで再生（2タップ）
- 案2（ホーム画面にアイコン）：「ファイル」アプリ → ブラウズ → 「Google ドライブ」をオンにする（ドライブアプリ側で「ファイル」連携を許可）→ 「M&Aニュース音声」の `ma_news_latest.mp3` を長押し →「よく使う項目」に追加、またはショートカットアプリで「ファイルを開く」アクションにこのファイルを指定し「ホーム画面に追加」（案2は実機で未確認。うまくいかなければ案1にする）
